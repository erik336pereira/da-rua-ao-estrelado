# Da Rua ao Estrelado

Uma partida inteira separa você do estádio! Corra, pule, use a cabeçada e o carrinho, e chute bolas para abrir caminho. Desvie dos cartões do juiz, fuja do goleiro que salta em sua direção e enfrente o chefão: um cartão vermelho vivo, com braços e pernas, que arremessa cartões e golpeia de perto. Recolha corações e bolas, sobreviva ao percurso e entre em campo.

**Jogo individual de plataforma 2D para computador.** Escolha a versão para Windows para baixar ou jogue a versão Web diretamente no navegador.

## Como jogar no navegador

Na página do itch.io, clique em **Run game**. A versão Web roda no navegador e não precisa instalar o Godot.

Se baixar o arquivo da versão Web para jogar localmente, extraia todos os arquivos para uma pasta. Abra o PowerShell nessa pasta e execute `py -m http.server 8000`; depois acesse `http://localhost:8000` no navegador. Caso `py` não funcione, tente `python -m http.server 8000`. Mantenha os arquivos juntos e não abra `index.html` por duplo clique. Para encerrar o servidor local, pressione **Ctrl+C** no terminal.

## Controles

- **A / D** ou **← / →** — mover
- **Espaço**, **W** ou **↑** — pular
- **J** — cabeçada
- **K** — carrinho
- **L** — chutar uma bola (consome munição)
- **P** ou **Esc** — pausar / voltar
- **Enter** — iniciar ou continuar
- **R** — reiniciar durante a pausa

## Sobre o jogo

Atravesse uma fase de plataforma inspirada no futebol, recolha recursos e enfrente o juiz, o goleiro/VAR, a torcida e o chefe Cartão Vermelho. Derrote o chefe para abrir o portão do estádio. O jogo apresenta telas de título, fase, pausa, derrota e vitória, além de músicas e efeitos sonoros originais.

## Downloads

- **Windows:** pacote compactado com o executável para PC.
- **Navegador:** build HTML5 exportada pelo Godot, para hospedar como projeto Web no itch.io.
