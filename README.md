# As aventuras de um jogador

Jogo de plataforma 2D de futebol feito em Godot 4.7.2, com gráficos desenhados no próprio jogo e trilhas e efeitos sonoros originais.

## Como jogar

- **A / D** ou **← / →**: mover
- **Espaço**, **W** ou **↑**: pular
- **J**: cabeçada de curta distância
- **K**: carrinho de curta distância
- **L**: chutar uma bola (consome munição)
- **P** ou **Esc**: pausar e voltar
- **Enter**: iniciar, retomar ou jogar novamente

Derrote os adversários, recolha bolas e corações, vença o chefe Cartão Vermelho e siga até o portão do estádio.

## Abrir o projeto

Abra `project.godot` no Godot 4.7.2. O projeto usa GDScript e o renderizador Compatibility, sem plugins externos. Para regenerar o áudio original, execute `python tools/generate_audio.py`.

## Exportar

Os exports Windows e Web são configurados em `export_presets.cfg`. Instale os templates de exportação correspondentes na mesma versão do Godot antes de exportar. A versão Web deve ser enviada ao itch.io como projeto HTML jogável no navegador.
